# Equilibrium

Настольное приложение для структурированной самостоятельной работы по протоколам с исследованной эффективностью. Всё хранится на вашем компьютере в зашифрованном виде, модель работает локально, наружу не уходит ничего.

[English](README.md)

## Что это

Программа ведёт упражнение по шагам: разбирает, что вышло с намеченным действием, помогает увидеть повторяющуюся цепочку «что было перед этим → что почувствовал → что сделал вместо → к чему привело», и доводит следующее действие до конкретики — когда, где, сколько, что может помешать.

Чем это не является: терапией, лечением, диагностикой и заменой помощи специалиста. Программа не оценивает ваше состояние и не ставит диагнозов, потому что делать это по переписке невозможно, а имитация такой оценки вредна.

Для кого не предназначено: острые мысли о самоповреждении, мания, психоз. В этих состояниях нужен живой человек.

## Как устроено

**Шагами управляет код, а не языковая модель.** Модель формулирует реплику текущего шага и ничего не решает: не выбирает за вас действие, не переходит к следующей теме, не может пропустить шаг, потому что убедительно об этом попросили. Последовательность держит конечный автомат.

**Каждая реплика проходит через проверку риска до генерации.** Проверка детерминированная и не спрашивает модель: большие модели ведут себя непоследовательно как раз на промежуточных формулировках вроде «иногда думаю, что не хочу жить». При срабатывании упражнение прерывается и показываются кризисные ресурсы. Статическим текстом, без участия модели.

**Ответ модели проверяется перед показом.** Отсекаются поддакивание, готовые советы, списки вариантов вместо ваших слов, изображение чувств. Не прошло — переформулировка с замечанием; не прошло второй раз — шаг задаёт свой обычный вопрос. Простой честный вопрос лучше складного нарушения протокола.

**Динамика измеряется вашими формулировками, а не опросниками.** Вы называете 2–4 трудности своими словами и оцениваете их по десятибалльной шкале. Идиографические меры чувствительнее к изменению, чем нормативные шкалы: в прямом сравнении PSYCHLOPS против CORE-OM размер эффекта 1,53 против 1,06.

**Данные лежат в одном зашифрованном файле.** База целиком держится в памяти, на диск пишется зашифрованный блоб (XChaCha20-Poly1305, ключ из пароля через Argon2id). Незашифрованного файла базы не существует ни в один момент. Пароль нигде не хранится: забыли — записи не восстановить.

Журнал срабатываний защиты содержит время, тип и что было предпринято. Текста сообщений в нём нет.

## Чего в программе нет намеренно

- Серий, значков, очков и любой геймификации. Удержание она не улучшает, а в исках к разработчикам чат-ботов такой дизайн описан как дефект конструкции.
- Уведомлений с эмоциональным давлением. Напоминание приходит только о том, что вы сами запланировали на назначенное вами время.
- Имени, аватара и биографии у программы.
- Свободного разговора без выхода на действие. Выговаривание само по себе не работает: в мета-анализе 154 исследований размер эффекта −0,02.
- Типологий личности. MBTI, соционика и подобное не имеют прогностической валидности, а ретестовая ненадёжность на уровне типа делает отслеживание динамики бессмысленным.
- Автоматического определения эмоций по тексту или голосу.

## Установка

Скачайте сборку для своей системы на странице релизов и запустите.

Для диалога нужна локальная модель через [Ollama](https://ollama.com):

```
ollama pull qwen3:8b
```

Без Ollama программа работает: каждый шаг задаёт свой обычный вопрос, но живого диалога не будет.

## Сборка из исходников

Нужны Rust и Node.js 20+.

```
npm install
npm run tauri build
```

Системных зависимостей нет: криптография и SQLite собираются из исходников, OpenSSL не требуется.

## Ограничения

Честный список того, что здесь плохо.

**Клинических испытаний не проводилось.** Протокол опирается на исследования поведенческой активации, но само это приложение никто не проверял. Единственное испытание генеративного терапевтического агента (Therabot, NEJM AI, 2025) шло при непрерывном надзоре персонала: за восемь недель на 106 человек потребовалось 28 вмешательств, из них 13 — чтобы исправить ответы самого бота. Автономная работа не проверена никем.

**Кризисные линии указаны только для США и Великобритании.** Номера для других стран не добавлены, потому что непроверенный номер кризисной линии хуже, чем его отсутствие. Если знаете проверенный номер со ссылкой на официальный источник — присылайте.

**Качество локальной модели ограничено.** На 8 ГБ видеопамяти помещаются модели, которые держат инструкции через раз. Проверка ответов это компенсирует, но ценой того, что часть реплик заменяется обычным вопросом шага.
